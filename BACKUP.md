# 🔐 Подсигуряване на СИСТЕМАТА — чеклист

Системата живее на 3 места: кодът в GitHub, данните в Supabase (Postgres),
файловете в Supabase Storage. Кодът е най-малкият риск (git пази пълната
история във всяко копие) — ценността са ДАННИТЕ.

## 1. Акаунти (най-важно)
- [ ] GitHub → Settings → Password and authentication → включи 2FA
- [ ] Supabase → Account → Security → включи 2FA

## 2. Локално копие на кода
Еднократно (компютър в офиса):
    git clone https://github.com/dankogeorgiev/dankosystemscode.git
Опресняване (от време на време, в папката):
    git pull
Без Git: GitHub → Code → Download ZIP → на външен диск.

## 3. Данните (Supabase)
- Платеният план прави автоматични ДНЕВНИ бекъпи (пазят се 7 дни):
  Dashboard → Database → Backups — провери, че се виждат.
- Веднъж месечно: свали бекъп локално от същата страница (за история
  извън 7-те дни).

## 4. Второ отдалечено копие на кода (по желание)
GitLab (безплатно) → New project → Import project → Repository by URL →
адреса на GitHub репото → включи Pull mirroring. Обновява се само.

## 5. Файловете (Storage)
- Чертежите по RFQ се свалят с отметките + „⬇ Свали избраните" (админ).
- При нужда от пълен архив на всички файлове — да се направи админ
  бутон/скрипт (говори с Клод).
