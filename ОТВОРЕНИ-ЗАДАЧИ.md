## 2. 🟠 Supabase Edge функции — чакат ръчен redeploy

Кодът им е в хранилището (`supabase/functions/…`), но НЕ е качен в Supabase.

| Функция | Какво носи новото |
|---|---|
| `parse-document` | издател на фактурата, сверка на сумите, падеж, килограми |
| `daily-mail` | секция „Свършено вчера" + понеделнишки план |
| `send-inquiry` | прикачени файлове (PDF на фактурата към имейла) |

Плюс еднократно SQL в Supabase → SQL Editor:

```sql
alter table partners add column if not exists eik text;
alter table partners add column if not exists mol text;
```

## 3. 🟡 По избор — довършване на резервните копия

- **Слой 2 (огледало на кода)** работи без настройка. Ако искаш и второ
  хранилище извън GitHub: направи празно репо в GitLab и добави secret
  `MIRROR_URL` = `https://ПОТРЕБИТЕЛ:ТОКЕН@gitlab.com/…/repo.git`
- **Файловете от Storage** (чертежи, PDF-и) още НЕ влизат в нощното копие —
  кажи и добавям стъпка, която ги тегли.
- **Слой 3 (ръчен архив)** е готов и работи: ЕРП → ⤓ Импорт (xlsx) →
  долу „🗄 Направи резервно копие". Прави го поне веднъж седмично.

## 4. 🟢 Предложения, които чакат твоята дума

- Предупреждение при пускане в производство, ако детайл е с **отрицателна
  наличност** („оправи с ръчна корекция преди да пуснеш"), с корекция от
  същия прозорец.
- **Контрол на качеството** в Боядисване (конвейр) — гейтът още не е сложен там.
- **Авто-раздаване** на задачите по служители („раздай поравно по капацитет").
- Инструмент за **разделяне на конкретна съществуваща серия** (сега сливането
  се изключва само за напред, по цехове).
