## ✅ ГОТОВО: резервните копия

| Слой | Какво пази | Кога | Статус |
|---|---|---|---|
| 1. Нощен pg_dump | цялата база, криптирана | всяка нощ 04:00 | ✅ работи (изпълнение №7, 05.08.2026) |
| 2. Огледало на кода | код + цялата история | неделя 04:30 | ✅ работи |
| 3. Ръчен архив | всички таблици, на компютъра | по желание | ✅ работи (ЕРП → ⤓ Импорт → 🗄) |

**Къде се вземат копията:**
https://github.com/Dankogeorgiev/DankosystemsCODE/actions/workflows/backup-supabase.yml
→ влизаш в изпълнение → най-долу **Artifacts** (пазят се 90 дни).

**Възстановяване** (иска Gpg4win на Windows):

```
gpg --decrypt --output backup.tar supabase-2026-08-05.tar.gpg
tar -xf backup.tar
pg_restore --no-owner --no-privileges -d "ВРЪЗКАТА" supabase-2026-08-05.dump
```

Само една таблица: `pg_restore … -t tasks`
Файлът `.sql` е четим текст — става и за поглед с очи.

⚠ **Паролата `BACKUP_PASSPHRASE` трябва да е записана извън GitHub.** Без нея
копието не се отваря от никого — включително от теб.

⚠ Свали ръчно едно копие веднъж месечно и го сложи на външен диск. Артефактите
живеят 90 дни; ако акаунтът в GitHub изчезне, изчезват и те.

## 🟠 1. Supabase Edge функции — чакат ръчен redeploy

Кодът им е в хранилището (`supabase/functions/…`), но НЕ е качен в Supabase.

| Функция | Какво носи новото |
|---|---|
| `parse-document` | издател на фактурата, сверка на сумите, падеж, килограми |
| `daily-mail` | секция „Свършено вчера" + понеделнишки план |
| `send-inquiry` | прикачени файлове (PDF на фактурата към имейла) |

Плюс еднократно SQL в Supabase → SQL Editor:

```sql
alter table partners add column if not exists eik text;
alter table partners add column if not exists mol text;
```

## 🟡 2. По избор — довършване на копията

- **Файловете от Storage** (чертежи, PDF-и на фактури) още НЕ влизат в нощното
  копие. Кажи и добавям стъпка, която ги тегли.
- **Второ хранилище за кода** извън GitHub: направи празно репо в GitLab и
  добави secret `MIRROR_URL` =
  `https://ПОТРЕБИТЕЛ:ТОКЕН@gitlab.com/…/repo.git`. Тогава кодът се бута и там
  всяка неделя.

## 🟢 3. Предложения, които чакат твоята дума

- Предупреждение при пускане в производство, ако детайл е с **отрицателна
  наличност** („оправи с ръчна корекция преди да пуснеш"), с корекция от
  същия прозорец.
- **Контрол на качеството** в Боядисване (конвейр) — гейтът още не е сложен там.
- **Авто-раздаване** на задачите по служители („раздай поравно по капацитет").
- Инструмент за **разделяне на конкретна съществуваща серия** (сега сливането
  се изключва само за напред, по цехове).
