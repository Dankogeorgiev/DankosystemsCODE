# AI разчитане на заявки — настройка

Качваш сканирана клиентска заявка (PDF/снимка) → Claude я разчита → ти
потвърждаваш → ражда се нормална заявка с **нашия код**, вързан към рецептата.
API ключът стои в **Edge функция в Supabase**, никога в браузъра.

Ключът `ANTHROPIC_API_KEY` вече е зададен (ползва се и от асистента 🤖), затова
остава само да качиш новата функция.

## Стъпка 1 — Качи Edge функцията `parse-document`
**Вариант А (през браузъра):**
1. Supabase → проекта → **Edge Functions** → *Deploy a new function*.
2. Име: **parse-document**
3. Постави съдържанието на `supabase/functions/parse-document/index.ts` (от репото).
4. Deploy.

**Вариант Б (през CLI):**
```bash
supabase functions deploy parse-document --project-ref hwbblteomrrahfrsyuow
```

## Стъпка 2 — Секретът (ако още не е зададен)
Supabase → **Project Settings** → **Edge Functions** → **Secrets**:
- `ANTHROPIC_API_KEY` = `sk-ant-...`

(Ако асистентът 🤖 вече работи — ключът е зададен, пропусни тази стъпка.)

## Стъпка 3 — Bucket за файлове
Ползва се съществуващият публичен bucket **`drawings`** (същият като файловете на
заявките). Не е нужен нов bucket.

## Готово — как се ползва
1. Склад/ЕРП → **Заявки от клиенти** → бутон **🤖 Разчети заявка (AI)**.
2. Избери PDF/снимка → **Разчети**.
3. Отваря се двупанелен екран: **вляво оригиналът, вдясно разчетените редове**.
   - Зелено ● = висок шанс (авто-вързан); Оранжево ● = предложение; Червено ● = избери ръчно.
   - Свери количества/цени, избери наш продукт където липсва, отметни **ревизия ✓**.
4. **Потвърди** → създава заявката + запомня съответствията „техен код → наш код".

## Как „се учи"
Съответствията се пазят в `app_config` (id `product_aliases`), по клиент.
При всяко потвърждение новите двойки (клиентски код → наш продукт) се записват,
затова **следващата заявка от същия клиент** разпознава кодовете автоматично.
Не е трениране на модела — расте таблица със съответствия, която е прозрачна и
може да се коригира.

## Настройки
- **Модел / цена:** в `index.ts` променливата `MODEL` (по подразбиране
  `claude-sonnet-5` — по-точен на документи; при стабилно качество може
  `claude-haiku-4-5-20251001` за по-евтино).
- **Одитна следа:** суровият отговор на AI се пази в заявката (`aiParsed`), а
  оригиналният файл — в Storage, вързан за заявката.
