## А. Brevo (https://www.brevo.com)

1. Влез в акаунта (или направи нов, безплатен — 300 мейла/ден).
2. **Домейн автентикация (най-важното — за пълна доставимост):**
   - Brevo → **Senders, Domains & Dedicated IPs → Domains → Add a domain** → `dankosystems.com`
   - Brevo ще ти покаже 2–3 DNS записа (DKIM ключ `mail._domainkey` или подобен,
     Brevo code TXT, евентуално DMARC).
   - Отвори **cPanel → Zone Editor** за dankosystems.com (файлът, който ми прати)
     → **Add Record** → добави записите ТОЧНО както ги дава Brevo (тип TXT/CNAME,
     име и стойност 1:1).
   - Обратно в Brevo → **Authenticate** — до няколко минути домейнът светва ✅.
3. **Добави подателя**: Senders → Add a sender → `zapitvane@dankosystems.com`
   (кодът за потвърждение идва в webmail-а: https://jump22.jump.bg:2096/).
   При автентикиран домейн понякога не иска и код.
4. **API ключ**: SMTP & API → API Keys → Generate a new API key → копирай го.

## Какво може Системата (след настройката)

| Откъде | Бутон | Какво праща |
|---|---|---|
| Заявка / Фактура | 🚚 Запитване за транспорт | маршрут, палети и тегло — попълнени сами; получател от Контактите |
| Покупка | ✉ Заявка до доставчика | редовете на покупката (код/артикул/кол.), имейл от партньорите |
| Заявка | ✉ бутона за клиента | „✅ Готова е" или „📅 В производство — очаквана дата (срокът)" |

| Контакти | Запитване до доставчици | масово запитване (BCC) |
| Автоматично 07:30 | — | сутрешен отчет: просрочени вземания + задължения |
